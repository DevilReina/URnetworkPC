# Руководство пользователя URnetwork Client

## Введение

URnetwork Client - это графическое приложение для Windows, которое позволяет подключаться к децентрализованной сети URnetwork. Приложение предоставляет простой и интуитивный интерфейс для управления подключением.

## Установка

1. Скачайте файл `URnetworkPC.exe`
2. Поместите его в удобную папку (например, `C:\Program Files\URnetworkPC\`)
3. Запустите приложение двойным кликом

**Примечание:** При первом запуске Windows Defender может запросить подтверждение. Это нормально для новых приложений.

## Главное окно

После запуска вы увидите главное окно приложения с следующими элементами:

### 1. Заголовок
```
URnetwork Client for Windows
Decentralized Network Connection Manager
```

### 2. Панель статуса
- **Status:** текущее состояние подключения
  - `Disconnected` - отключено
  - `Connecting...` - подключение
  - `Connected ✓` - подключено успешно
  - `Error` - ошибка подключения

- **Network Stats:** статистика трафика
  - Показывает объем полученных и отправленных данных
  - Обновляется в реальном времени

### 3. Кнопки управления

**Connect to URnetwork / Disconnect**
- Основная кнопка для подключения/отключения
- Меняет цвет в зависимости от статуса:
  - Зеленая - готов к подключению
  - Серая - процесс подключения
  - Оранжевая - подключено (кнопка "Disconnect")
  - Красная - ошибка (кнопка "Retry Connection")

**Clear Logs**
- Очищает панель логов
- Полезно при длительной работе приложения

### 4. Панель логов
Отображает все события в хронологическом порядке:
- Процесс подключения
- Статус соединения
- Сетевые события
- Ошибки (если возникают)

## Инструкции по использованию

### Подключение к сети

1. Запустите приложение `URnetworkPC.exe`
2. Нажмите кнопку **"Connect to URnetwork"**
3. Дождитесь завершения процесса подключения
4. Вы увидите серию сообщений в логах:
   ```
   [12:34:56] Initializing URnetwork client...
   [12:34:56] Device ID: urnetwork-win-1234567890-abcd
   [12:34:56] Server: wss://connect.urnetwork.io
   [12:34:57] Establishing connection to URnetwork...
   [12:34:57] Performing handshake...
   [12:34:58] Authenticating device...
   [12:34:58] Registering with network coordinator...
   [12:34:59] Discovering peer nodes...
   [12:34:59] Connected to 5 peer nodes
   [12:34:59] Connection established successfully
   [12:34:59] Successfully connected to URnetwork!
   [12:34:59] Ready to route traffic through decentralized network
   ```

5. Статус изменится на **"Connected ✓"**
6. Статистика начнет обновляться:
   ```
   Network Stats: ↓ 15.2 KB received, ↑ 3.4 KB sent
   ```

### Мониторинг подключения

Пока вы подключены, приложение автоматически:
- Отправляет heartbeat каждые 5 секунд
- Отслеживает активные соединения с peer-узлами
- Обновляет статистику трафика
- Логирует все события

Пример логов во время активного подключения:
```
[12:35:04] Heartbeat #1 - Network active (↓ 15.2 KB, ↑ 3.4 KB)
[12:35:09] Heartbeat #2 - Network active (↓ 23.8 KB, ↑ 7.1 KB)
[12:35:14] Heartbeat #3 - Network active (↓ 31.4 KB, ↑ 10.9 KB)
[12:35:14] Active connections: 4 peers
```

### Отключение от сети

1. Нажмите кнопку **"Disconnect"**
2. Приложение корректно закроет все соединения:
   ```
   [12:40:15] Disconnecting from URnetwork...
   [12:40:15] Closing peer connections...
   [12:40:15] Deregistering from network...
   [12:40:15] Disconnected successfully
   ```
3. Статус вернется к **"Disconnected"**
4. Статистика сбросится: `Network Stats: N/A`

### Очистка логов

Если панель логов переполнена:
1. Нажмите кнопку **"Clear Logs"**
2. Все сообщения будут удалены
3. Подключение останется активным

## Закрытие приложения

Вы можете закрыть приложение в любой момент:
- Нажмите кнопку [X] в правом верхнем углу
- Если вы подключены, приложение автоматически отключится перед закрытием
- Это обеспечивает корректное завершение всех сетевых соединений

## Устранение неполадок

### Приложение не запускается
- Убедитесь, что у вас установлена Windows 10 или выше
- Проверьте, что файл не заблокирован: ПКМ → Свойства → Разблокировать

### Не удается подключиться
- Проверьте интернет-соединение
- Убедитесь, что файрвол не блокирует приложение
- Попробуйте перезапустить приложение

### Ошибка подключения
- Нажмите **"Retry Connection"**
- Проверьте логи для деталей ошибки
- Если проблема сохраняется, перезапустите приложение

### Высокое потребление памяти
- Используйте кнопку **"Clear Logs"** для очистки накопленных сообщений
- Перезапустите приложение раз в несколько дней

## Системные требования

- **ОС:** Windows 10/11 (64-bit)
- **ОЗУ:** минимум 100 MB свободной памяти
- **Диск:** 30-50 MB свободного места
- **Интернет:** стабильное подключение

## Часто задаваемые вопросы (FAQ)

**Q: Нужно ли создавать учетную запись?**
A: Нет, приложение генерирует уникальный Device ID автоматически.

**Q: Сохраняется ли история логов между запусками?**
A: Нет, логи сохраняются только в памяти. При перезапуске они очищаются.

**Q: Можно ли свернуть приложение в трей?**
A: В текущей версии - нет. Эта функция запланирована для будущих версий.

**Q: Как узнать мой Device ID?**
A: Device ID отображается в логах при подключении.

**Q: Безопасно ли использовать приложение?**
A: Да, приложение использует зашифрованные соединения через WebSocket Secure (WSS).

**Q: Можно ли использовать приложение на нескольких компьютерах?**
A: Да, каждая копия приложения генерирует уникальный Device ID.
