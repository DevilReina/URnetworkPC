# URnetwork Client для Windows

Полнофункциональный GUI-клиент для Windows на базе концепции сетевого протокола URnetwork, разработанный на Go с использованием библиотеки Fyne.

## 🎯 Возможности

- 🖥️ **Графический интерфейс (GUI)** - современный, интуитивный интерфейс для Windows
- 🔌 **Управление подключением** - подключение/отключение к сети URnetwork одной кнопкой
- 📊 **Статистика в реальном времени** - отслеживание входящего и исходящего трафика
- 📝 **Панель логов** - подробное логирование всех событий подключения
- 🔄 **Неблокирующая архитектура** - все сетевые операции выполняются в горутинах
- 🛡️ **Обработка ошибок** - корректная обработка ошибок и восстановление
- 💻 **Thread-safe** - безопасная работа с многопоточностью

## 📋 Требования

- **Go:** версия 1.20 или выше
- **ОС:** Windows 10/11 (или Linux/macOS для разработки)
- **Зависимости:**
  - fyne.io/fyne/v2 (GUI библиотека)

## 🚀 Быстрый старт

### Установка зависимостей

Для Windows необходимы дополнительные инструменты для компиляции Fyne:

1. **Установите Go 1.20+** с официального сайта: https://golang.org/dl/

2. **Установите GCC (MinGW-w64):**
   - Скачайте MSYS2 с https://www.msys2.org/
   - Установите и запустите MSYS2
   - Выполните команды:
     ```bash
     pacman -Syu
     pacman -S mingw-w64-x86_64-gcc
     ```
   - Добавьте `C:\msys64\mingw64\bin` в PATH

3. **Скачайте зависимости Go:**
   ```bash
   go mod download
   go mod tidy
   ```

### Сборка

#### Вариант 1: Разработка (с консолью для отладки)
```bash
go build -o URnetworkPC.exe
```

#### Вариант 2: Продакшн (без консоли, оптимизированный)
```bash
go build -ldflags="-H windowsgui -s -w" -o URnetworkPC.exe
```

#### Вариант 3: Использование скриптов сборки

**Windows (PowerShell):**
```powershell
.\build.ps1
```

**Linux/macOS (кросс-компиляция):**
```bash
chmod +x build.sh
./build.sh
```

Флаги сборки:
- `-H windowsgui` - скрывает консольное окно в Windows
- `-s -w` - уменьшает размер бинарника (удаляет отладочную информацию)

## 💡 Использование

1. Запустите `URnetworkPC.exe`
2. В открывшемся окне нажмите кнопку **"Connect to URnetwork"**
3. Приложение подключится к сети URnetwork
4. Логи подключения отображаются в нижней панели
5. Статистика трафика обновляется в реальном времени
6. Для отключения нажмите **"Disconnect"**
7. Используйте кнопку **"Clear Logs"** для очистки логов

## 🏗️ Архитектура

### Основные компоненты

#### 1. **URnetworkClient** - управление сетевым подключением
   - Инициализация клиента URnetwork
   - Управление жизненным циклом подключения
   - Мониторинг состояния соединения
   - Thread-safe логирование
   - Отслеживание сетевой статистики

#### 2. **URnetworkGUI** - графический интерфейс
   - Главное окно приложения
   - Кнопки управления (Connect/Disconnect, Clear Logs)
   - Индикатор статуса с визуальной обратной связью
   - Панель логов с автопрокруткой
   - Отображение статистики трафика

### Состояния подключения

- **Disconnected** - отключено от сети
- **Connecting** - процесс подключения
- **Connected** - успешно подключено
- **Error** - ошибка подключения

### Неблокирующая архитектура

Все сетевые операции выполняются в отдельных горутинах для предотвращения блокировки GUI:

- **Подключение к сети** - выполняется в отдельной горутине
- **Мониторинг соединения** - фоновая горутина с тикером (5 сек)
- **Обновление UI** - тикер с интервалом 500мс
- **Логирование** - thread-safe с использованием mutex

### Thread Safety

- `sync.RWMutex` для защиты статуса подключения
- `sync.Mutex` для защиты логов
- Каналы и context для управления горутинами

## 🔧 Решение проблем

### Проблема: "gcc: command not found"
**Решение:** Установите MinGW-w64 (см. раздел "Установка зависимостей")

### Проблема: Окно консоли мигает при запуске
**Решение:** Используйте флаг `-H windowsgui` при сборке

### Проблема: Большой размер .exe файла
**Решение:** Используйте флаги `-ldflags="-s -w"` для уменьшения размера

### Проблема: Ошибки при кросс-компиляции
**Решение:** Убедитесь, что установлен mingw-w64-gcc:
```bash
# Linux
sudo apt-get install gcc-mingw-w64-x86-64
# macOS
brew install mingw-w64
```

## 📦 Интеграция с реальным URnetwork SDK

Текущая версия содержит **реалистичную mock-реализацию** URnetwork клиента для демонстрации архитектуры приложения.

Для интеграции с реальным SDK `github.com/urnetwork/connect`:

1. Обновите `go.mod`:
```go
require github.com/urnetwork/connect latest
```

2. Замените mock-методы в `URnetworkClient`:
```go
func (c *URnetworkClient) connectInternal() error {
    // Используйте реальный API URnetwork SDK
    client, err := connect.NewClient(connect.Config{
        DeviceId: c.config.DeviceID,
        // другие параметры конфигурации
    })
    if err != nil {
        return err
    }
    return client.Start(c.ctx)
}
```

3. Настройте обработчики событий SDK согласно документации URnetwork
