# URnetwork Client - Quick Start Guide

## 🚀 Для пользователей Windows

### Шаг 1: Получите приложение
Скачайте готовый `URnetworkPC.exe` или соберите сами (см. ниже).

### Шаг 2: Запустите
Двойной клик на `URnetworkPC.exe`

### Шаг 3: Подключитесь
Нажмите кнопку **"Connect to URnetwork"** в окне приложения.

### Готово!
Вы подключены к децентрализованной сети URnetwork. Статистика трафика отображается в реальном времени.

## 🛠️ Для разработчиков

### Требования
- Go 1.20+
- GCC (MinGW-w64 для Windows или mingw-w64-gcc для кросс-компиляции)

### Установка зависимостей

**Windows:**
```bash
# Установите MSYS2 с https://www.msys2.org/
# Затем в MSYS2 терминале:
pacman -Syu
pacman -S mingw-w64-x86_64-gcc
# Добавьте C:\msys64\mingw64\bin в PATH

# Скачайте зависимости Go:
go mod download
go mod tidy
```

**Linux (для кросс-компиляции в Windows):**
```bash
sudo apt-get install gcc-mingw-w64-x86-64
go mod download
go mod tidy
```

**macOS (для кросс-компиляции в Windows):**
```bash
brew install mingw-w64
go mod download
go mod tidy
```

### Быстрая сборка

**На Windows:**
```bash
# Разработка (с консолью)
go build -o URnetworkPC.exe

# Продакшн (без консоли)
go build -ldflags="-H windowsgui -s -w" -o URnetworkPC.exe

# Или используйте скрипт:
.\build.ps1
```

**Кросс-компиляция (Linux/macOS → Windows):**
```bash
chmod +x build.sh
./build.sh

# Или вручную:
GOOS=windows GOARCH=amd64 CGO_ENABLED=1 CC=x86_64-w64-mingw32-gcc \
  go build -ldflags="-H windowsgui -s -w" -o URnetworkPC.exe
```

### Разработка

```bash
# Запустить в режиме разработки
go run main.go

# Форматирование
go fmt ./...

# Проверка кода
go vet ./...
```

## 💡 Основные компоненты

### 1. URnetworkClient
Управляет подключением к сети:
- Инициализация и подключение
- Мониторинг соединения (heartbeat каждые 5 сек)
- Отслеживание статистики
- Thread-safe операции

### 2. URnetworkGUI
Графический интерфейс:
- Кнопки Connect/Disconnect, Clear Logs
- Индикация статуса с визуальной обратной связью
- Панель логов с автопрокруткой
- Отображение статистики трафика

## 🔧 Флаги сборки

| Флаг | Описание |
|------|----------|
| `-H windowsgui` | Скрывает консольное окно в Windows |
| `-s` | Удаляет таблицу символов (уменьшает размер) |
| `-w` | Удаляет отладочную информацию (уменьшает размер) |

**Пример:**
```bash
go build -ldflags="-H windowsgui -s -w" -o URnetworkPC.exe
```

## 🎓 Архитектурные решения

### Конкурентность
- **Подключение** - отдельная горутина с defer/recover
- **Мониторинг** - фоновая горутина с ticker (5 сек)
- **UI обновление** - ticker (500 мс)

### Thread Safety
- `sync.RWMutex` - для статуса подключения (много чтений, мало записей)
- `sync.Mutex` - для логов (защита от race condition)
- `context.Context` - для graceful shutdown

### Управление состоянием
```
Disconnected → Connecting → Connected → Disconnected
      ↓              ↓
    Error  ←─────────┘
```

## ❓ Быстрые ответы на вопросы

**Q: Работает ли это на macOS/Linux?**
A: Да! Fyne кроссплатформенный. Просто удалите флаг `-H windowsgui`.

**Q: Как интегрировать реальный URnetwork SDK?**
A: См. раздел "Интеграция с реальным URnetwork SDK" в `README.md`.

**Q: Можно ли уменьшить размер .exe?**
A: Да, используйте флаги `-s -w` и опционально UPX compression.

**Q: Нужна ли учетная запись?**
A: Нет, Device ID генерируется автоматически.

**Q: Сохраняются ли логи между запусками?**
A: Нет, в текущей версии логи только в памяти.
